Clipping web pages into a Markdown research vault

If you keep notes in Obsidian, Logseq or a plain Git repo, the web pages you read are part of your research too: a blog post, an API docs page, a long-form article. Bookmarks rot and browser tabs pile up. A Markdown copy, with the source URL at the top, stays searchable for years. This is the clipping routine I use.

Why not just copy and paste?

Copying from the rendered page drags in navigation, cookie banners and "related posts", and it flattens headings into bold text. Converting from the URL works better: fetch the page, find the main content and turn its HTML structure into Markdown. The URL to Markdown converter on dochost fetches a public page and returns GitHub-flavored Markdown with the headings, links, lists and tables intact.

The clipping template

---
title: Original title
source: https://example.com/article
author: Name
published: 2026-10-02
clipped: 2026-11-11
tags: [topic, project]
---
> One-sentence reason I saved this.

(converted article)

What to keep and what to cut

  • Keep: headings, code blocks, tables, and links that are part of the argument.
  • Cut: share buttons, newsletter boxes, comments, "you might also like".
  • Images: keep the remote URLs only for diagrams you need, and download the important ones, because remote images break too.

Cite properly

When you quote a clipped page in your own writing, link the original URL, not your copy. Your Markdown file is a reading copy, not a republication. Keep clippings private unless the license allows sharing.

When you need the raw HTML instead

Sometimes the Markdown loses what you came for: a page's exact markup, its meta tags or structured data. For those cases, URL to HTML returns the page's HTML source so you can save or inspect it.

Weekly maintenance

  1. Process the inbox folder: tag each clipping or delete it.
  2. Add a link from at least one of your own notes. An unlinked clipping is a dead clipping.
  3. Re-check sources you rely on, since docs pages change. Note the clipped date.
